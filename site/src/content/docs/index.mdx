Livefire is a self-hosted multiplayer server. Your game backend creates a room over HTTP and gives each player a join token. Players connect over WebSocket to exchange messages, share state, or move through a server-simulated world.

<dl class="guide-list">
  <dt><a href="/docs/multiplayer-server/">Run a room</a></dt>
  <dd>Start the local counter example. Two players join, send a chat message, and see the same counter.</dd>
  <dt><a href="/docs/self-hosting/">Host a server</a></dt>
  <dd>Deploy with Docker Compose, configure HTTPS, and create your first room with curl.</dd>
  <dt><a href="/docs/self-hosting/#already-run-a-pds">Use an existing PDS</a></dt>
  <dd>Let players sign in with an existing AT Protocol account, or create guest accounts on a Personal Data Server you run.</dd>
</dl>

## Connect your game

Use the [TypeScript SDK](https://github.com/HolotypePteLtd/livefire/tree/master/sdk/typescript) or the [Dart client](https://github.com/HolotypePteLtd/livefire/tree/master/packages/client). For other languages, follow the [WebSocket client guide](/docs/protocol-clients/).
